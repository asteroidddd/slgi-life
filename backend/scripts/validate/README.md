# scripts/validate

데이터 품질, 스키마, 공간 데이터 정합성을 확인하는 검증 스크립트를 두는 위치입니다.

## 검증 범위

| 카테고리 | 대상 | 예 |
|---|---|---|
| 스키마 검증 | 모델/DB 정합 | 컬럼, 제약, 인덱스 존재 확인 |
| 데이터 품질 | NULL, 범위, 분포 | 점수 0~100 범위, 좌표 서울 BBOX |
| 공간 검증 | SRID, Geometry, 인덱스 | EPSG:4326, geom NULL 여부, GiST 인덱스 |
| 재실행성 | idempotent 키 | 중복 적재 여부, upsert 기준 |

## 운영 방식

- 업데이트 실행 전에는 DB 연결, migration 상태, 필수 파일 존재 여부를 확인합니다.
- 업데이트 실행 후에는 행 수, 점수 범위, 좌표 범위, 주요 API 조회 가능 여부를 확인합니다.
- 검증 실패 시 후속 파생 데이터 업데이트나 배포를 중단하는 방향으로 구성합니다.

현재 폴더는 검증 스크립트 추가를 위한 자리입니다. 검증 로직이 추가되면 실행 명령과 실패 기준을 이 문서에 함께 기록합니다.
